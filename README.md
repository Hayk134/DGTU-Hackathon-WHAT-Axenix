# WHAT — Java Blueprints (Enterprise IDE & Visual AI Suite)

> Интерактивная среда визуального программирования, статического анализа, декомпозиции монолитов и AI-оптимизации Java 21 с гарантией сохранения семантики (Quality Gate).
> **Разработано для кейса «Java Blueprints» (Axenix Hackathon).**

---

## 1. Архитектура и технологический стек

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      FRONTEND (Vue 3 + Vite + Tailwind)                 │
│  ┌───────────────────────┬────────────────────────┬──────────────────┐  │
│  │ Vue Flow (Blueprints) │ Monaco Editor (Java21) │ MiniMap & Heatmap│  │
│  └───────────────────────┴────────────────────────┴──────────────────┘  │
│         ▲                                                    │          │
│         │ Двусторонняя реактивная синхронизация (AST / CFG)   │          │
│         ▼                                                    ▼          │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ Audit Center: PDF / HTML / Markdown / Экспорт графа в PNG и JPEG  │  │
│  └───────────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────▲────────────────────────────────────┘
                                     │ REST API (JSON / UTF-8)
┌────────────────────────────────────▼────────────────────────────────────┐
│                    BACKEND (Kotlin 1.9 + Ktor Netty)                    │
│  ┌────────────────────────┬────────────────────────┬─────────────────┐  │
│  │ ASTParser (JavaParser) │ StaticAnalyzer (Big-O) │ Quality Gate    │  │
│  └────────────────────────┴────────────────────────┴─────────────────┘  │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ Hybrid Optimizer: Gemini 3.8 Flash (AI) + Deterministic AST Rules │  │
│  │ Verification Engine: системный javac (JDK 21) + JVM Sandbox       │  │
│  └───────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Frontend:** Vue 3 (Composition API), Vite 8, Tailwind CSS, Vue Flow, Monaco Editor, `html-to-image` (2x Ultra HD экспорт).
- **Backend:** Kotlin 1.9, Ktor 2.3 (Netty), JavaParser 3.25 (полная поддержка грамматики Java 21).
- **AI-ядро:** Двухуровневый гибридный пайплайн:
  1. *AI Optimizer*: Google Gemini 3.8 Flash / Flash-Lite с контекстом дефектов и фокусом на алгоритмы.
  2. *AST Rule Engine*: Детерминированное устранение квадратичных вложенных циклов ($O(n^2) \to O(n)$ через `HashMap`/`HashSet`), ликвидация строковых конкатенаций в циклах (`StringBuilder`), оптимизация коллекций.
- **Quality Gate (Zero-Regression):** Компиляция реальным `javac` (JDK 21) в изолированном временном каталоге, запуск тестов в песочнице с лимитами памяти/таймаута, побайтовое сравнение `stdout`, `stderr` и кодов возврата.

## 2. Функциональные возможности и ключевые фичи

| Подсистема | Возможности и назначение |
| :--- | :--- |
| **Control Flow Blueprints** | Интерактивное построение графа потока управления (CFG) на уровне AST: ветвления `if/else`, `switch/case`, циклы `for`, `foreach`, `while`, блоки выражений, вызовы методов и точки выхода (`return`, `throw`, `break`). |
| **Overview Grid & Method Tabs** | Архитектурный карточный обзор методов класса (`Overview Grid`) и изолированные вкладки отдельных методов (`Method Tabs`). Устраняет падение FPS на монолитах в тысячи строк кода. |
| **Static Big-O Analyzer** | Автоматическое обнаружение алгоритмических узких мест: $O(n^2)$/$O(n^3)$ вложенные циклы, неэффективные методы в теле циклов (`contains`, `indexOf`), высокая цикломатическая сложность, длинные методы и дублирование кода. |
| **Hybrid Code Optimizer** | Комплексная оптимизация: AI-рефакторинг (Gemini) + AST-правила. Замена $O(n^2)$ вложенных поисков на быстрые хэш-индексы ($O(n)$ / $O(1)$), сборка строк через `StringBuilder`. |
| **Monolith Decomposer** | Автоматический анализ графа вызовов и разрезание монолитных классов на слабосвязанные сервисные слои (`*Core`, `*Processor`, `*Helper`, `*Support`, `*Main`) с генерацией фасада. |
| **JDK 21 Quality Gate** | 100% гарантия сохранения поведения: запуск реального `javac` JDK 21, прогон набора golden master тестов, побайтовая сверка `stdout`, `stderr`, кодов возврата и замер времени (Benchmark). |
| **Visual Diff Inspector** | Встроенный инспектор изменений (Unified и Split / Side-by-side) с подсветкой синтаксиса и безопасным применением патчей в 1 клик. |
| **Audit Center & Export** | Формирование официального аудиторского заключения в PDF/HTML, выгрузка Markdown-таблицы для PR/Git, а также **растровый экспорт графа в PNG (2x Ultra HD) и JPEG**. |

## 3. Премиальный UX/UI и эргономика рабочего места

Интерфейс спроектирован на стыке строгого индустриального минимализма **JetBrains IDE** и кинематографичной наглядности нодовых графов **Unreal Engine 5**.

### 3.1. Фирменная палитра Dark Graphite & Brushed Silver
- **Глубокие графитовые поверхности** (`#040507` $\to$ `#0c0e15` $\to$ `#121620`) защищают зрение разработчика при многочасовой работе и создают ощущение профессионального инженерного инструмента.
- **Металлические акценты Brushed Silver** (`.jb-btn-silver`) на ключевых действиях («Импорт», «Export Java», «Отчет») и фирменный знак «W» гармонично контрастируют с темным фоном.
- **Приглушенные семантические акценты** (Sage, Titanium, Ash) вместо ярких кричащих рамок: статус-индикаторы не отвлекают от анализа архитектуры.

### 3.2. Интерактивная тепловая карта (Complexity Heatmap) & MiniMap
- **Честный спектр сложности:** узлы графа и переходы окрашиваются на основе реальных расчетов AST и цикломатики:
  - 🔴 **Красный ($O(n^3)$ / Cyclomatic $\ge 8$):** критические узлы, требующие немедленного рефакторинга.
  - 🟠 **Оранжевый ($O(n^2)$ / Cyclomatic $\ge 4$):** квадратичные циклы и средние дефекты.
  - 🟡 **Желтый ($O(n)$):** условные переходы и ветвления.
  - 🟢 **Зеленый ($O(1)$):** чистые базовые инструкции и примитивы.
- **Синхронизированный MiniMap:**
  - В обычном режиме карта отображается в сдержанных графитовых тонах.
  - При включении Heatmap карта синхронно вспыхивает тепловым спектром сложности.
  - Интерактивная навигация: клик центрирует холст, двойной клик открывает вкладку метода и мгновенно прыгает к коду в редакторе.

### 3.3. Двусторонняя реактивная синхронизация (Graph ↔ Monaco)
- **Monaco Editor уровня VS Code:** полноценный редактор с номерами строк, автодополнением и подсветкой синтаксиса Java 21.
- **Связь «Узел $\leftrightarrow$ Строка»:** выбор любого блока на графе моментально подсвечивает и прокручивает соответствующую строчку в редакторе (и наоборот).
- **Инспектор узла:** прямое редактирование выражений в боковом инспекторе с применением на лету (`Ctrl+Enter`) и удаление узлов клавишей `Delete` с вырезанием из AST.

### 3.4. Гибкая организация рабочего пространства
- **Перетаскиваемый сплиттер:** плавная регулировка соотношения между графом и нижней панелью (консоль, Diff, метрики, верификация).
- **Максимизация графа в 1 клик:** кнопка разворачивания холста во весь экран для удобного исследования масштабных схем.
- **Быстрые пресеты высоты:** переключение разделения экрана (30%, 50%, 70%, 100%).

## 4. Быстрый запуск

### Запуск в 1 клик (Windows):
```bat
start-all.bat
```
*Скрипт проверяет окружение, при необходимости автоматически устанавливает зависимости npm, запускает бэкенд на Ktor (порт 8080), дожидается готовности API, поднимает Vite (порт 5173) и открывает браузер.*

### Ручной запуск:

#### 1. Backend (Ktor + Netty):
```bash
cd Backend
./gradlew run
```
*Сервис доступен на `http://localhost:8080`. Проверка здоровья: `http://localhost:8080/api/health`.*

#### 2. Frontend (Vue 3 + Vite):
```bash
cd frontend
npm install
npm run dev
```
*Веб-интерфейс открывается на `http://localhost:5173`.*

### Тестирование и сборка:
```bash
# Тесты бэкенда (юнит-тесты верификатора и качества)
cd Backend
./gradlew test

# Проверка типов и продакшн-сборка фронтенда
cd ../frontend
npm run build
```

## 5. Использование с реальными Java-проектами

1. **Импорт:** Нажмите кнопку **`[Импорт]`** в верхнем тулбаре и выберите любой Java-файл или папку проекта (`.java`).
2. **Анализ и навигация:** Структура методов и граф управления (CFG) строятся автоматически. Доступны переключение между методами во вкладках, тепловая карта Big-O и MiniMap.
3. **Оптимизация и декомпозиция:** Кнопки **`Оптимизировать`**, **`AI Оптимизация`** и **`Декомпозировать`** устраняют узкие места и делят монолит на модули. Изменения открываются в режиме Diff для предварительного просмотра.
4. **Применение и Quality Gate:** Нажмите **`Применить в проект`** для обновления графа и редактора. Кнопка **`▶ Run`** компилирует и запускает код в песочнице JDK 21.
5. **Экспорт отчетов и графики:** Кнопка **`Отчет`** позволяет экспортировать официальный PDF-бланк, Markdown-отчет или снимки графа в PNG (2x Ultra HD) и JPEG.
