# WHAT — Java Blueprints (Enterprise IDE & Visual AI Suite)

> Интерактивная среда визуального программирования, статического анализа, декомпозиции монолитов и AI-оптимизации Java 21 с гарантией сохранения семантики (Quality Gate).
> **Разработано для кейса «Java Blueprints» (Axenix Hackathon).**

---

```

│  ┌───────────────────────┬────────────────────────┬──────────────────┐  │
│  │ Vue Flow (Blueprints) │ Monaco Editor (Java21) │ MiniMap & Heatmap│  │
│  └───────────────────────┴────────────────────────┴──────────────────┘  │
│         ▲                                                    │          │
│         │ Двусторонняя реактивная синхронизация (AST / CFG)   │          │
│         ▼                                                    ▼          │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ Audit Center: PDF / HTML / Markdown / Экспорт графа в PNG и JPEG  │  │
│  └───────────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────▲────────────────────────────────────┘
                                     │ REST API (JSON / UTF-8)
┌────────────────────────────────────▼────────────────────────────────────┐
│                    BACKEND (Kotlin 1.9 + Ktor Netty)                    │
│  ┌────────────────────────┬────────────────────────┬─────────────────┐  │
│  │ ASTParser (JavaParser) │ StaticAnalyzer (Big-O) │ Quality Gate    │  │
│  └────────────────────────┴────────────────────────┴─────────────────┘  │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ Hybrid Optimizer: Gemini 3.8 Flash (AI) + Deterministic AST Rules │  │
│  │ Verification Engine: системный javac (JDK 21) + JVM Sandbox       │  │
│  └───────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Frontend:** Vue 3 (Composition API), Vite 8, Tailwind CSS, Vue Flow (Unreal Engine Blueprint-style вкладки, карточный обзор, изоляция методов), Monaco Editor, `html-to-image` (2x Ultra HD экспорт).
- **Backend:** Kotlin 1.9, Ktor 2.3 (Netty), JavaParser 3.25 (полная поддержка грамматики Java 21).
- **AI-ядро:** Двухуровневый гибридный пайплайн:
  1. *AI Optimizer*: Google Gemini 3.8 Flash / Flash-Lite Relay с контекстом дефектов и фокусом на алгоритмы.
  2. *AST Rule Engine*: Детерминированное устранение квадратичных вложенных циклов ($O(n^2) \to O(n)$ через `HashMap`/`HashSet`), ликвидация строковых конкатенаций в циклах (`StringBuilder`), оптимизация коллекций.
- **Quality Gate (Zero-Regression):** Компиляция реальным `javac` (JDK 21) в изолированном временном каталоге, запуск тестов в песочнице с лимитами памяти/таймаута, побайтовое сравнение `stdout`, `stderr` и кодов возврата.

## 2. Ключевые возможности решения

### 2.1. Unreal Engine Blueprint Визуализация
- **Overview Grid (Карточный обзор):** Структура класса отображается в виде карточной сетки методов с индикаторами цикломатической сложности, бейджами Big-O и дефектами.
- **Method Tabs (Изолированные вкладки методов):** Открытие отдельного графа потока управления (CFG) для каждого метода. Исключает лаги браузера на тяжелых монолитах (1000+ строк).
- **Двусторонняя реактивная синхронизация:**
  - Правка кода в Monaco за 500 мс перестраивает граф.
  - Клик по узлу графа подсвечивает строку в Monaco и центрирует позицию.
  - Редактирование Java-выражений прямо в инспекторе узла (`Ctrl+Enter`).
  - Удаление узлов клавишей `Delete` с вырезанием из AST.

### 2.2. Интерактивная тепловая карта (Complexity Heatmap) & MiniMap
- **Честный расчет сложности:** Анализ реальных вложенностей AST (`for`, `foreach`, `while`, `if`, `switch`) и цикломатики:
  - 🔴 **Красный:** $O(n^3)$ / High defect / цикломатическая сложность $\ge 8$.
  - 🟠 **Оранжевый:** $O(n^2)$ / Medium defect / цикломатическая сложность $\ge 4$.
  - 🟡 **Желтый:** $O(n)$ / ветвления и условные переходы.
  - 🟢 **Зеленый:** $O(1)$ / линейные операции и примитивы.
- **Интерактивный MiniMap:**
  - Двусторонняя навигация: клик центрирует холст, даблклик открывает вкладку метода и прыгает к коду в Monaco.
  - Синхронизация состояния: в обычном режиме MiniMap отображается в спокойных темных тонах, при включении Heatmap загорается спектром тепловой карты.

### 2.3. Автоматическая декомпозиция монолитов
- Кнопка **«Декомпозировать»** проводит связный анализ вызовов методов.
- Монолит разделяется на чистые архитектурные слои: `*Core.java`, `*Processor.java`, `*Helper.java`, `*Support.java` и входной фасад `*Main.java`.
- Просмотр изменений в Antigravity-style Unified/Split Diff с подсветкой синтаксиса.

### 2.4. Аудиторский центр и визуальный экспорт (Кнопка «Отчет»)
- **Печать в PDF / Фирменный HTML:** Корпоративный аудиторский отчет со сводными метриками Big-O, таблицами дефектов, результатами Quality Gate и расчетом ускорения алгоритмов.
- **Скачать Markdown (.md):** Структурированный отчет для Git / Pull Request.
- **Экспорт графа в PNG (.png):** Снимок архитектуры графа высокого разрешения 2x Ultra HD без сжатия с темным фоном.
- **Экспорт графа в JPEG (.jpg):** Оптимизированное растровое изображение для презентаций и слайдов жюри.

## 3. Быстрый запуск

### Запуск в 1 клик (Windows):
```bat
start-all.bat
```
*Скрипт проверяет окружение, запускает бэкенд на Ktor (порт 8080), дожидается готовности API, поднимает Vite (порт 5173) и открывает браузер.*

### Ручной запуск:

#### 1. Backend (Ktor + Netty):
```bash
cd Backend
./gradlew run
```
*Сервис доступен на `http://localhost:8080`. Проверка здоровья: `http://localhost:8080/api/health`.*

#### 2. Frontend (Vue 3 + Vite):
```bash
cd frontend
npm install
npm run dev
```
*Веб-интерфейс открывается на `http://localhost:5173`.*

### Тестирование и сборка:
```bash
# Тесты бэкенда (юнит-тесты верификатора и качества)
cd Backend
./gradlew test

# Проверка типов и продакшн-сборка фронтенда
cd ../frontend
npm run build
```

## 4. Использование с реальными Java-проектами

1. **Импорт:** Нажмите кнопку **`[Импорт]`** в верхнем тулбаре и выберите любой Java-файл или папку проекта (`.java`).
2. **Анализ и навигация:** Структура методов и граф управления (CFG) строятся автоматически. Доступны переключение между методами во вкладках, тепловая карта Big-O и MiniMap.
3. **Оптимизация и декомпозиция:** Кнопки **`Оптимизировать`**, **`AI Оптимизация`** и **`Декомпозировать`** устраняют узкие места и делят монолит на модули. Изменения открываются в режиме Diff для предварительного просмотра.
4. **Применение и Quality Gate:** Нажмите **`Применить в проект`** для обновления графа и редактора. Кнопка **`▶ Run`** компилирует и запускает код в песочнице JDK 21.
5. **Экспорт отчетов и графики:** Кнопка **`Отчет`** позволяет экспортировать официальный PDF-бланк, Markdown-отчет или снимки графа в PNG (2x Ultra HD) и JPEG.
