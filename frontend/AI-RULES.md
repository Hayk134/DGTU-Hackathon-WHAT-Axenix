## §0 Workflow — перед написанием любого кода

1. **Контекст задачи хакатона. ОБЯЗАТЕЛЬНО.** Продукт — профессиональный IDE-инструмент для Java-разработчиков и архитекторов. Пользователь загружает монолит ~1000 строк, исследует и модифицирует его через граф (Control Flow Graph), устраняет дефекты $O(n^2)$, декомпозирует на классы и автоматически доказывает сохранение поведения через Quality Gate.
2. **Никакой воды и маркетинга. ОБЯЗАТЕЛЬНО.** Запрещены лендинговые блоки («Q3 Release», «Купить», фальшивые декоративные сферы). Интерфейс сразу открывается в полноценное рабочее пространство IDE (редактор, холст, инспектор, раннер тестов).
3. **Токены перед вёрсткой. ОБЯЗАТЕЛЬНО.** Все цвета, отступы и радиусы берутся строго из таблицы токенов §1 и §11.
4. **Стек поставки. ОБЯЗАТЕЛЬНО:** Vue 3 (Composition API), TypeScript, TailwindCSS, `@vue-flow/core`, Monaco/CodeMirror или кастомный JetBrains Mono Editor.

## §2 Эргономика JetBrains New UI (`IDE` & `CMP`)

**IDE-01 — ОБЯЗАТЕЛЬНО.** Компоновка рабочего пространства состоит из 5 канонических зон:

1. **Main Toolbar (h-10 / 40px)** — единая верхняя строка:
   - Слева: логотип `JB` + селектор проекта `Java Blueprints [monolith]` + хлебные крошки (`src › Main.java`).
   - По центру: **Unified Run Widget** (сегментированный блок: имя конфигурации `Main [Application]` + кнопка `▶ Запуск` + быстрая оптимизация `⚡`).
   - Справа: Inspection Widget (`0 ошибок, 1 дефект`), Search Everywhere (`⌘K`), действия импорта/экспорта.
2. **Tool Window Stripe (w-10 / 38px)** — крайняя левая вертикальная полоса с квадратными иконками инструментов (`📁 Project`, `🧩 Blocks Palette`, `📊 Inspection`). Клик разворачивает/сворачивает панель без скачков верстки.
3. **Collapsible Tool Window (w-60 / 240px)** — компактная панель дерева файлов или палитры блоков.
4. **Центральная рабочая зона (Сплит 50/50 или 60/40)**:
   - Верхний этаж: холст Control Flow Graph (Vue Flow) на темном фоне с точечной координатной сеткой.
   - Нижний этаж: прямоугольные вкладки редактора (`Main.java ×`), окно кода с номерами строк и JUnit Test Runner.
5. **Status Bar (h-6 / 24px)** — нижняя строка состояния: ветка Git `⎇ main`, Quality Gate статус, `Ln:Col`, кодировка `UTF-8`, рантайм `OpenJDK 17`, индикатор памяти.

## §4 Узлы графа в стиле JetBrains (`NOD`)

**NOD-01 — ОБЯЗАТЕЛЬНО.** Узлы графа — это **не круглые пилюли**, а компактные технические блоки:
- **Радиус скругления:** строго `6px` (`rounded-md`).
- **Структура блока:**
  1. Верхняя полоса-заголовок (высота 24px) с типом конструкции (`METHOD`, `IF`, `LOOP`, `RETURN`), иконкой и номером строки `:48`.
  2. Тело узла (фон `#10131a`, волосяная серебряная рамка `border-white/[0.14]`) с текстом Java-выражения в моноширинном шрифте.
  3. Коннекторы портов (Handle Pins) сверху и снизу: квадратные контакты 8×8px из шлифованного серебра.
- **Связи (Edges):** серебряные линии толщиной 1.5px с деликатной точечной анимацией потока данных (`animation: flowEdge`).

## §5 Кнопки и контролы JetBrains (`CTA`)

**CTA-01 — ОБЯЗАТЕЛЬНО.** Все кнопки и поля интерфейса имеют радиус **4px** (`rounded-[4px]`) и фиксированную эргономичную высоту:
- **Primary Action (Run / Main):** высота `28px`, плотная заливка градиентом шлифованного серебра (`linear-gradient(180deg, #ffffff 0%, #cbd5e1 50%, #94a3b8 100%)`), темный текст `#090b10`, начертание 600, верхний микро-блик `inset 0 1px 0 #ffffff`.

- **Segmented Run Widget:** цельный блок с разделителями, объединяющий выбор конфигурации и кнопку запуска.

**CTA-02 — ЗАПРЕЩЕНО.** Круглые кнопки-пилюли с радиусом `999px` для IDE-интерфейса.

## §6 Требования хакатона Axenix: Java Blueprints (`HCK`)

**HCK-01 — КЛЮЧЕВОЙ КОНТРАКТ.** После любых преобразований (оптимизация $O(n^2)$, декомпозиция монолита) автоматические тесты **обязаны доказывать, что поведение программы сохранилось на 100%**.
- Сравнение вывода `System.out` должно выполняться побайтово.
- Поддержка кодировки `StandardCharsets.UTF_8` для работы с кириллицей обязательна.

**HCK-02 — ОБЯЗАТЕЛЬНЫЙ JAVA SCOPE:**
1. Язык и `java.lang`: классы, интерфейсы, примитивы, циклы (`for`, `while`, `foreach`), ветвления (`if/else`, `switch`), методы, конструкторы, `try/catch/finally`.
2. Консольный ввод/вывод: `System.in`, `System.out`, `Scanner`, `Formatter`, `printf`.
3. Коллекции `java.util`: `List`, `Set`, `Map`, `ArrayList`, `HashMap`, `Iterator`, `Collections`, `Arrays`.
4. Исключения: checked/unchecked, кастомные Exception.

**HCK-03 — ЗАПРЕЩЕННЫЙ SCOPE (ВНЕ РАМОК ХАКАТОНА):**
- Многопоточность (`java.util.concurrent`), рефлексия (`reflection`), работа с файлами (`nio.file`), сетевые сокеты, работа со временем (`java.time`). Не тратить на них время.

**HCK-04 — ДИАГНОСТИКА BIG O И ДЕФЕКТОВ:**
- Детект вложенных циклов по коллекциям ($O(n) \to O(n^2)$) на конкретных строках.
- Диагностика длинных методов (>40 строк).
- Замер эмпирического времени выполнения (бенчмарк на $N = 100 \dots 10,000$).
- Кнопка «Оптимизировать» должна производить реальный AST-патч: замену вложенного цикла на `HashMap`/`HashSet`.

**HCK-05 — ДЕКОМПОЗИЦИЯ МОНОЛИТА:**
- Автоматическое разделение монолита `Main.java` (~1000 строк) на 4 изолированных файла ответственности: `Parser.java`, `Analyzer.java`, `Optimizer.java`, `Main.java`.

## §7 Анимация и микровзаимодействия (`MOT`)

**MOT-01 — ОБЯЗАТЕЛЬНО.** В профессиональном devtools-интерфейсе анимации должны быть **мгновенными и быстрыми**:
- Переключение вкладок, ховеры кнопок: `150ms ease`.
- Разворачивание боковой панели: `200ms cubic-bezier(.16, 1, .3, 1)`.
- Движение импульсов по связям графа: `1.2s linear infinite`.
- **ЗАПРЕЩЕНО:** длинные 1-секундные задержки появления, блокирующие работу пользователя.

## §8 Запреты (Anti-Patterns) — `BANS`

1. **ЗАПРЕЩЕНО:** Большие радиусы `999px` (пилюли) на кнопках IDE.
2. **ЗАПРЕЩЕНО:** Яркие неоновые цвета (салатовый, желтый, синий, маджента).
3. **ЗАПРЕЩЕНО:** Декоративные лендинговые баннеры, фальшивые отзывы и маркетинговые плашки.
4. **ЗАПРЕЩЕНО:** Фейковые моковые числа — метрики должны вычисляться по реальному коду через AST-анализ.
5. **ЗАПРЕЩЕНО:** Разделители `·` и `•` в интерфейсе — использовать `›`, `/` или волосяные бордеры.
6. **ЗАПРЕЩЕНО:** Эмодзи операционной системы (`🔥`, `⭐`) в основных панелях. Использовать монохромные векторные глифы или `JetBrains Mono` символы.
