# Java Blueprints — Frontend

Vue 3 + Vite + Tailwind + Vue Flow интерфейс для работы с backend Java Blueprints.

## Возможности

- загрузка Java-файлов и отправка их в backend;
- визуализация AST-графа и статического анализа;
- редактирование кода с повторным парсингом через backend;
- оптимизация и декомпозиция проекта через backend;
- проверка компиляции и сохранения поведения через backend.

Frontend не содержит встроенных демо-проектов или тестовых моков.

## Запуск

```bash
npm run dev
```

Frontend: `http://localhost:5173`  
Backend: `http://localhost:8080`

## Сборка

```bash
npm run build
```
